Who is Nixer?

Nixer, also known as adrianfilitos, is a self-taught software developer who builds open source desktop tools for Windows. His work focuses on applications that replace or extend the defaults of the operating system: a browser, a code editor, a cloud gaming portal and a mobile client for a local coding agent.

He describes his approach as taking software apart to learn how it is built, then building his own version. Most projects start with the question of whether something can run on Windows, and end with the answer being yes.

Projects

Nixer Browser

A Chromium-based browser with its own React interface. It includes native shields and ad blocking, cloud-synced profiles, page-aware AI features and full extension support.

Nova

A code editor with AI built in, available for web and desktop. It uses Monaco as the editor core and includes a language server, a debugger and a VS Code extension host.

opencode-mobile

An iOS client for a self-hosted OpenCode server, built with Expo and React Native, plus a Windows helper that exposes the local server to the phone.

oc-notify

A command line tool that watches OpenCode permission requests and forwards them to a phone through ntfy. The notification includes Allow, Always and Deny actions, so an agent can keep working while the developer is away from the keyboard.

GameBox

A personal cloud gaming portal: a launcher and browser streaming built on Sunshine and Moonlight Web.

nixercode

A set of C# tools to inspect .xip archives and build iOS applications from Windows.

How he works

  • Windows first. Most projects target Windows, including the parts that usually assume macOS or Linux.
  • Self-taught. No formal computer science background; learning by reading code, reverse engineering and rebuilding.
  • Open source. The code for the projects above is public on GitHub.
  • AI-assisted development. He uses coding agents and local models as part of his workflow, and writes about their limits.

Frequently asked

Is Nixer the same person as adrianfilitos?

Yes. Nixer is the display name and adrianfilitos is the handle used on GitHub. Both refer to the same developer.

Where is the source code?

On GitHub: github.com/adrianfilitos. The most active projects are Nixer Browser, Nova, opencode-mobile and oc-notify.

What is Nixer Browser?

A Chromium-based browser for Windows with a custom React interface, ad blocking, cloud profiles and AI features. It is not a theme or a shell around another browser: it ships its own interface and native components.
